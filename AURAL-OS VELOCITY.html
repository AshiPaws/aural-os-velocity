Method 1 (Fastest & Native): You don't need a full compilation step! You can install this app directly onto your Pixel 9 as a native PWA app without a computer.

1. Open Google Chrome on Pixel 9
2. Tap Chrome Menu (3 dots )
3. Tap "Add to Home screen" or "Install app"

Convert this app into a signed .APK or .AAB file using Microsoft's official free PWABuilder tool:

  1. Host this index.html file on GitHub Pages, Netlify, or Vercel.
  2. Visit PWABuilder.com in your browser.
  3. Enter your hosted web URL and tap Package for Android.
  4. Download the generated .apk file directly to your Pixel 9 and install it!

Use Capacitor to turn this single HTML file into a complete Android Studio project:

# 1. Initialize Capacitor project

npm init @capacitor/app

# 2. Add Android platform

npm install @capacitor/android

npx cap add android

# 3. Copy index.html to www/ and build APK

npx cap run android
